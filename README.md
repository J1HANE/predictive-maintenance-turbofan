# Predictive Maintenance for Turbofan Engines

A Python project for exploring predictive maintenance on the NASA C-MAPSS turbofan engine dataset. It builds a Bronze/Silver/Gold data pipeline, engineers sensor features, estimates remaining useful life (RUL), and provides a Streamlit fleet dashboard.

> **Project status:** This is a portfolio and learning project. The streaming module is an in-process telemetry simulation, and the maintenance report assistant uses hand-authored SOP examples and deterministic rules. It does not connect to a Kafka broker or an external LLM/vector database. Predictions and recommended actions are demonstrations and are not suitable for operational maintenance decisions.

## What it includes

- Data ingestion for NASA C-MAPSS, with synthetic-data generation as an offline fallback.
- Bronze, Silver, and Gold Parquet transformations.
- Rolling sensor features, a health index, and piecewise RUL targets.
- Random forest RUL regression, a Kaplan–Meier estimator, and a Cox proportional hazards implementation.
- A cost-threshold maintenance policy example and a KS-test drift monitor.
- A simulated telemetry producer/consumer and rule-based maintenance report generator.
- A Streamlit dashboard for fleet status, sensor trends, survival estimates, cost thresholds, reports, and drift results.

## Setup

Requires Python 3.10 or newer. From the project root:

```bash
python -m venv .venv
source .venv/bin/activate     # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Get the data

The data files are intentionally excluded from this repository. The downloader attempts to fetch NASA C-MAPSS and generates synthetic sample data if the download is unavailable:

```bash
python -m src.data.download_data
```

The downloader writes files under `data/raw/`. Review the dataset's terms and attribution requirements before redistributing it. The synthetic fallback is generated by this project and should not be presented as NASA data.

## Run the dashboard

```bash
streamlit run app/dashboard.py
```

The dashboard builds the FD001 data lake when the required Gold Parquet files are missing. Its cost optimization view currently illustrates a noisy baseline prediction rather than loading a trained model.

## Run the demo pipeline

```bash
python main.py
```

This executes the FD001 pipeline, model examples, simulated telemetry, drift calculation, and report generation. It writes intermediate Parquet files under `data/`, MLflow artifacts under `mlruns/`, and a report under `reports/`; these are local generated artifacts.

## Run tests

```bash
pytest
```

## Data source

The project is designed around the NASA C-MAPSS turbofan engine degradation benchmark. The downloader currently uses a GitHub-hosted mirror for convenience. Verify the original dataset source and applicable terms before public redistribution.
